GTASA CO-OP v2 — сетевой прототип для Android

Что умеет этот проект:
- Создаёт UDP-сессию для обмена тестовыми сообщениями по локальному Wi‑Fi/точке доступа.
- Можно указать IP хоста и порт.
- Отправляет координаты X/Y/Z и действие (WALK, JUMP, VEHICLE).
- Показывает последнее полученное сообщение.

ВАЖНО:
Это сетевой прототип, а не готовый мультиплеер внутри GTA SA.
Он пока не читает координаты из игры, не создаёт второго CJ и не управляет GTA SA/CLEO.
Для реальной интеграции понадобится отдельный CLEO/нативный мост, совместимый с GTA SA Android 2.00.

Как собрать:
1. Создай новый репозиторий на GitHub.
2. Загрузи всё содержимое ZIP в корень репозитория (не загружай сам ZIP вместо содержимого).
3. Открой репозиторий в GitHub Actions/Android build workflow или импортируй проект в AndroidIDE.
4. Сборка может потребовать настройки Android SDK/Gradle; этот проект не был проверен сборкой в этой среде.

Проверка связи:
- Оба телефона должны быть в одной Wi‑Fi сети или один должен включить точку доступа, а второй подключиться к ней.
- На телефоне-хосте узнай локальный IP в настройках Wi‑Fi.
- На втором телефоне введи IP хоста и нажми «Подключиться».
- UDP-порт по умолчанию: 24680.
- Если Android блокирует обмен в фоне, оставь приложение открытым на обоих телефонах.
